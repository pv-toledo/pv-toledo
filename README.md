# Paulo Vinícius Vieira Toledo

**Full-Stack Software Engineer | MSc in Metallurgical Engineering**

*Building AI, optimization, and modern web applications with Python, TypeScript, and React.*

I'm a full-stack software engineer passionate about building products that combine modern web technologies, optimization, machine learning, and data.

I primarily work with Python, FastAPI, React, Next.js, TypeScript, and PostgreSQL, building end-to-end applications from backend APIs to responsive user interfaces.

Before transitioning into software engineering, I earned an MSc in Metallurgical Engineering. My research focused on thermodynamic modeling of complex industrial processes, which shaped the way I approach software engineering today: breaking down difficult problems, designing reliable systems, and building practical solutions.

*I enjoy turning complex real-world problems into simple, reliable software.*

## Featured Projects

### ⚡ [EAF Optimizer](https://github.com/pv-toledo/eaf-optimizer) · [Live Demo](https://eaf-optimizer.vercel.app)

Full-stack optimization platform that computes the lowest-cost material mix under real production constraints. Built with a FastAPI backend, a Next.js frontend, and a linear programming engine, featuring authentication, user-specific material catalogs, optimization history, and interactive parameter configuration.

`Python` · `FastAPI` · `Next.js` · `React` · `TypeScript` · `PostgreSQL` · `Linear Programming`

---

### 🏡 [ZOH Marketplace](https://zoh-marketplace.vercel.app) · [Repository](https://github.com/peguimasid/zoh-marketplace)

Luxury real estate marketplace for buying and renting properties. The platform includes location-based search, property listings, user authentication, and tools for property owners to publish and manage listings.

Developed collaboratively as a full-stack application. I was primarily responsible for the frontend architecture and implementation, while also contributing to Supabase integrations and backend features.

`Next.js` · `React` · `TypeScript` · `Supabase` · `PostgreSQL`

---

### 🤖 [Ladle Furnace Temperature Prediction](https://github.com/pv-toledo/ladle-furnace-ml)

Machine learning project that predicts liquid steel temperature using industrial process data. Built with feature engineering guided by domain knowledge and focused on producing interpretable models rather than treating the problem as a black box.

`Python` · `scikit-learn` · `XGBoost` · `Pandas`
